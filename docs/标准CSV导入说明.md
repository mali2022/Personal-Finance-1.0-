# 标准收支 CSV 导入

从导入页面下载 `import-template.csv`，使用 UTF-8 编码保存。模板仅用于支出和收入，转账使用独立模板。

| 字段 | 填写说明 |
| --- | --- |
| 日期时间 | 例如 `2026-10-07 12:30:00`，无时区时按北京时间解析 |
| 金额 | 实付或实收金额，必须大于零 |
| 交易类型 | `支出` 或 `收入` |
| 商户 | 交易对象，可留空 |
| 商品 | 支出商品名，可留空；收入说明填写在备注中 |
| 分类 | 已有一级分类名称或 ID |
| 二级分类 | 该一级分类下的已有二级分类名称或 ID |
| 三级分类 | 可留空；填写时须属于指定二级分类 |
| 备注 | 独立保存的补充说明，可留空 |
| 交易状态 | 成功或已入账记录可导入；失败、关闭、取消记录排除；处理中或无法识别的状态需要核对 |
| 币种 | 例如 `CNY`，须与选择的资金账户一致 |
| 优惠金额 | 支出优惠，非负；收入须为零或留空 |
| 交易单号 | 可选，便于来源追踪和重复记录检查 |

上传后选择资金账户，核对字段映射及预览结果，再确认入账。分类不会因导入自动创建，错误路径可在预览中明确选择正确分类。商品、备注和优惠金额可以在预览中编辑。

金额不会再次扣除优惠。例如金额 `25.50`、优惠金额 `4.50` 表示原价 `30.00`、实际支出 `25.50`，账户仅扣减 `25.50`。

原有单分类 CSV 和转账专用模板继续兼容。
