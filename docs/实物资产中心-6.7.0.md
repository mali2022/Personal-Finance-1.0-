# 实物资产中心 6.7.0

发布号：2026.10.22.3。入口：账户与资产 → 实物资产（`/physical-assets`）。

## 实施范围

- 总览：按币种分列已覆盖估值、原始及剩余成本、账面价值、折旧、数量、保值率、现金使用成本、持有成本、闲置率、分类集中度和有依据的更换成本。分类分布及近12个月同日快照提供图表及原始数据表；缺失估值明确标记。
- 独立三级分类：增删改、排序、停用、标签、默认估值模式及寿命。删除和合并只处理叶子分类；有子分类时先处理子分类，防止隐式改写分类树。合并迁移资产归属并保留审计。
- 档案：名称、编码、品牌、型号、序列号、购置日期及成本、启用日期、商户、币种、付款账户、照片和凭证HTTPS链接、保修到期、位置、状态、持有人、标签与备注。原始数量与成本保留，后续数量调整走处置。照片及凭证当前不提供直接上传。
- 估值：手动、直线折旧、余额递减、固定、市场观察及数量乘单价。原始成本、账面价值、市场价值和估计净变现价值分别保存。市场价和更换成本必须由用户填写来源，无自动市场报价接入。规则按日期追加，可追溯；旧手动估值保留兼容。直线折旧按实际寿命天数分摊，余额递减按年率逐日折算，寿命期满归至残值。
- 生命周期：新增待启用、启用、闲置、借出、维修、出租、转让、出售、报废、丢失及归档；转让、出售、报废和丢失支持部分数量。撤销从最近有效事件依次追加冲销记录，不删除审计。事件按发生日期顺序追加。
- 持有费用：维修、保养、保险、能源、维护、其他。仅关联同币种已确认的现有支出ID，整个交易只能归属一个资产。金额复用有效费用分录（含手续费）；取消关联不撤销原交易，已删除或失效交易不计入成本。不自动创建任何收支分录。
- AI：复用IAiProvider/现有DeepSeek接入、汇总授权、限流及授权版本复核，支持健康检查、成本解释、更换建议、自然语言检索。证据仅来自当前筛选的数据库快照，不发送照片、凭证、序列号、持有人、位置或备注；未知价格不可编造。自然语言检索只覆盖发送给AI的名称、分类、金额、状态和估值字段。
- 提醒：保修到期、维护、未估值、盘点及长期闲置，显示未来30天内应处理项；完成维护/盘点通过生命周期登记，重新计算周期。当前为应用内列表，不包含外部通知推送。

## 统一口径

资产中心与资产配置复用`PhysicalAssetMath`。原币分组，不跨币种直接相加；资产配置沿用现有指定日期直接汇率折算。持有汇总排除归档和已全部处置项。原始总成本不改写，剩余成本按剩余数量分摊；折旧为剩余成本减账面价值，持有成本为折旧加有效现金使用成本。

保值率以有估值资产的剩余成本为分母；闲置率按档案数量；集中度为最大分类占已覆盖估值比例。缺失估值及更换成本不视为真实零。较上月变化包含资产增减持影响，不等同于纯价格收益。分类、标签、持有人和位置为当前档案维度，历史趋势按当前筛选资产集合计算，不能用于重建历史分类调整。
