# 记账与资金往来操作优化 — 2026.10.25.1

产品版本：6.9.9；发布日期：2026-10-25（Asia/Shanghai）。

## 实现

- 记账及编辑日期提供今天、昨天、前天、现在快捷操作；日期快捷操作保留时分秒。
- 消费详情增加添加退款，自动关联原消费；原消费检索支持商户、备注、商品名、金额、交易编号和上海时区日期。
- 账户交易筛选使用账户关联 ID 集合，交易后余额仅计算本页涉及账户的完整流水；切换账户重置页码、取消过时请求，错误提供重试。
- 常规交易支持修改类型；切换时清理分类、付款拆分、优惠、手续费和原退款关联；服务端重建分录，保留并发版本及关联业务保护。
- 借出与借入列表、详情提供删除确认；服务端同一写事务撤销本金和有效还款并归档有效还款计划。
