# 十模块财务统计口径管理（6.6.0）

主功能发布号：2026.10.22.1；当前修复版本：6.6.1 / 2026.10.22.2。入口：设置与管理 → 财务统计口径管理（`/settings/statistics`）。

## 交付范围

按收入、支出、转账账户、信用贷款、投资资产、时间账期、预算储蓄、工资社保、币种汇率、数据质量十个模块展示85项规则，提供规则搜索。规则区分全账本配置、分析配置、固定核算原则、专项管理入口和尚缺核算数据；无数据支撑的项目不会显示可保存但不生效的开关。

提供日常记账、资产管理、综合财务、自定义四种方案。预设主要切换分析附表，日常方案隐藏投资和财富附表，资产方案展示投资财富并隐藏债务明细，综合方案展示全部附表；手动修改标记为自定义。选择预设保留用户币种、账期和大额阈值。预设将全账本三个开关恢复为手续费开启、损失和调减关闭，须显式保存后生效。

## 配置生效范围

- **全账本**：沿用手续费、资产损失、减少余额调整三个开关，作用于原收支报表和适用预算。固定排除内部转账、借贷及信用还款本金，不提供改变经济实质的本金计收入开关。
- **口径分析**：已关联现金奖励、存款利息、投资现金收入可选择纳入；依据实际业务关联识别，手工未关联收入保留，不按分类名称猜测。已标注一次性收入可从分析储蓄率基数中排除，支持交易优先及分类祖先继承。
- **时间**：自定义月起始日1—31日、财务年度起始月和周起始日。短月取月末，下月回到设定日。选择账期中的任意一天，期间采用上海时区、左闭右开；已发生分析仅统计已确认且生成时点之前的记录。
- **退款与储蓄**：费用可净额展示或费用退款分列，退款始终不重复计收入，储蓄率按退款后净费用计算；收入基数非正时标记不适用。
- **薪酬**：工资附表可按应发/实发、发薪日/归属月展示；归属月份按月初分组。应发、扣缴、更正、实发、关联到账、税费、个人社保、公积金及年终奖分别计算，不重复加入银行支出。
- **币种和质量**：基准币种决定分析默认原币，不自动折算旧交易。支持大额交易阈值和提示、未分类分录保留、未来及未结算记录排除提示；大额提示可打开原交易详情。

现有预算仍按既有CNY自然月及年度定义。账户冻结、可用和待入账余额由现有资金状态管理维护；投资费用及本金由投资模块维护。入账日统计、完整实物处置折旧、全账本历史外币折算及已实现汇兑成本尚缺数据支持，在目录明确说明。

## 多套指标与比较

预览只读，不写交易、余额或规则。服务端并列：

1. 日常收入、费用、到账退款、净支出、结余、储蓄率基数和储蓄率。
2. 流动账户现金流及结余率。同币种自有流动账户转账按交易抵销，信用还款和贷款本金仍体现现金压力；余额调整和资产损失排除现金流。账户逐行资金变动保留全量，不可直接相加为现金流入流出。
3. 债务到账、已还本金、信用还款、已核对利息/手续费/未分类费用、有效借入业务剩余本金、本账期计划余款和按自然月汇总。已撤销借款到账不再产生剩余本金，未核对费用不推定为零。
4. 投资已实现价差损益、分红利息、期末已覆盖浮盈、市值及估值缺口，复用既有投资成本引擎。投资费用已在成本或净所得中，不再次扣除。
5. 推算账面净资产变化及其与分析结余的差额、综合资产估值和未覆盖项。账户余额缺少历史期初生效日，不能将差额直接称作投资收益；综合估值不与账户金额再次相加。
6. 薪酬独立附表及数据质量说明。

同时计算服务器已保存方案；账期不同会提示数值差异包含时间范围变化。三个全账本开关另提供同一账期下的新旧支出差额。修改配置后，上次预览明确标记过期；预览不自动按30秒后台轮询，避免不必要查询。编辑期间不通过后台轮询覆盖草稿。

## 存储和接口

`GET/PUT /api/settings/statistics/management` 保存认证用户的方案，复用 StoredDocument 独立文档类型，无新增数据库迁移。PUT在原Write事务中同时检查方案If-Match及全账本规则版本，原子保存；冲突不覆盖，客户端保留编辑内容。

`POST /api/settings/statistics/management/preview` 接受 options、ledgerRules、anchor、period、currency，原币计算。`GET /api/settings/statistics/management/history` 仅返回当前用户最近50条方案或账本规则审计。审计内容限配置值，不包含正式账务金额或交易备注。旧三个统计规则API继续兼容。

开发Mock提供种子账本的基础口径与账户流量，明确提示未包含专项关联数据；生产构建排除Mock，专项结果由认证API提供。

独立测试库新增7元未分类费用及3元退款，验证4元净费用保留；关闭手续费后的分析预览、旧预览、统一报表、趋势及预算用量一致。补丁已另建新版本公告，未复用已发布版本号。
