## 兼容性及发布风险

- 新增表必须先运行 EF 迁移，再部署依赖它的 API。迁移只新增表、外键和索引，不回填或改写正式交易；旧 API 不依赖新字段。
- 查询保留旧参数及分页结构；非法类型、状态、排序与金额区间现在返回 422，依赖静默忽略非法参数的旧调用方需修正。多商户使用 JSON 字符串数组保存，以支持名称中的逗号，并兼容旧 CSV 参数；旧单商户参数不变。
- 统计是所选**整笔交易**的账本分录，不做按筛选账户或分类切割金额；跨币种按分录原币展示，不做缺失汇率估算。分类匹配分录后仍按整笔交易展示，避免拆分误解。
- 总支出为正费用分录；退款冲减净支出；平均、最大支出以普通 Expense 交易金额计；转出包括转账手续费；净现金流复用 AccountKinds.IsLiquid 的流动账户定义，仅含现金、银行、支付宝、微信及电子钱包；排除余额调整、资产损失与信用/合同账户分录，同币种流动账户间转账抵销并保留手续费。借款实际到账不会被负债分录抵销。回收站视图统计所选已删除记录的历史分录，不代表当前余额。
- 日期分组的小计覆盖该上海日期内全部匹配记录；跨页同一天会重复展示同一完整小计，不把分页小计冒充全天金额。
- 异常规则为明确、保守的初版规则：极端阈值为原币100000；重复线索要求时间/账户/类型/币种/金额/商户全同；余额规则检测缺少资金分录或分录本位金额不平衡，不把信用卡负余额视为错误。规则不会证明记录必错。
- 匹配基于用户核实的账单标识和带正负号的金额，支持差异与撤销历史；不是银行自动拉取账单服务。退款及跨币种转账仍以原有结构关联和双边分录为依据。
- 浏览器设置不跨设备同步；默认视图仅在没有显式 URL 参数时应用。损坏视图或存储写入失败必须明确报告且保留原数据。
- AI 模型输出不可信；生成建议不能自动写正式分类，搜索不接受 SQL 或任意字段。真实 DeepSeek 可用性需具备当前用户授权和有效服务配置；自动化测试用替代 provider 不等于真实联网验证。
- 本工作区有大量既有未提交改动；本次保留它们。生产发布须连同依赖的既有迁移、生产构建、版本校验及备份流程整体核对。
