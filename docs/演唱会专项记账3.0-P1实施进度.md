## 数据及口径

沿用StoredDocument JSON，无新表/迁移，保留当前94迁移及已上线投资收益率变更。保存复用Write事务/用户锁、If-Match、幂等及审计；档案只引用原资金事实，不新建流水，不自动冲销。关联可明确清空或重选并保留修改前后历史，不提供物理删除接口。

行程按各原币独立统计，跨行程付款归属不得超额、场次费用不得重复归属、其他场次/商品/返款占用不得冒充未分配；后续原交易改变会警告并停止计入。退款引用场次权威核验结果，主币行程预算按实付前退款口径，旅行专项预算按所选行程全周期，不按预算年度裁切。不同预算范围不可相加，也不重复设置资金预留。收藏整笔出售收支专用并排除其他用途、分次返款不得超实收，非出售状态须实收返款抵平；整笔预付款合同只关联一个收藏，未经认可的估值/预计尾款不计资产或负债。无原成本时显示未关联而非伪装零成本。

照片/票根复用现有场次及原购买附件服务，行程先关联场次再引用其凭证；视频仅存HTTP/HTTPS外部地址，无二进制视频入账。媒体外链可用性由原提供方决定。未来场次估算用用户输入假设，不提供虚构票价。目的地IANA时区保留，行程时间输入明确使用设备本地时间并保存绝对时刻；不是自动生成旅行/外部预订服务。
