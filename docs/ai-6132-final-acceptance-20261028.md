## 4. 本轮缺陷修复

1. **服务商 HTTP 400 工具重名**：删除重复的 Agent 投资工具定义，保留原领域入口；新增完整/只读工具注册表唯一性测试。
2. **全局工具被模型附加不支持的账户参数**：不支持账户筛选的工具 schema 不再公布 accountId；显式账户隔离仍由服务端拒绝越界请求。
3. **并行工具的授权复查共用 DbContext**：串行执行会话作用域的授权查询，业务查询继续在独立作用域并行；增加并行 SQL 回归。
4. **长区间被月度快捷计划收窄**：显式跨月、跨年及 ISO 非完整月区间不再强套首月计划；新增范围回归和真实长周期复测。
5. **统一授权遗漏描述字段**：补齐 Agent 最终读取结果对 FullFinancialAccess 的判断；旧的非全量只读许可仍保留脱敏。
6. **中文日期简写的数值核验**：增加只有落在单一查询来源范围内才豁免的日期简写核验；不允许范围外日期或未获依据的金额。初始偶发模型用例未保存失败原文，不能断言该格式是每次失败的唯一根因；后续已增加实际答复诊断。
7. **测试可靠性与兼容性**：修正两项仍要求预算阻断的旧断言；Fuel 用例按测试用户统计而非依赖整库为空；Ant Design 多步骤测试保留全部断言，采用 5 秒有界异步等待与 30 秒有界测试超时；浏览器用例按真实高级筛选、清除筛选和警告定位操作。
8. **迁移验证脚本**：启用 sqlcmd -I，满足过滤索引写入要求；不是跳过旧账或附件种子。

本轮未重新设计无限预算架构，未恢复内部费用、Token、模型/工具次数门槛。
