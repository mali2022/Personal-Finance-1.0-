## 2. Apple Design System

### 2.1 颜色（浅色优先，避免深色块）

- 底色 `--pf-bg: #F5F5F7`，卡片 `#FFFFFF`，分隔线 `rgba(60,60,67,.14)`，文字 `#1D1D1F / #6E6E73 / #8E8E93`。
- 主色 `#007AFF`；收益 `#1D8A46`、支出 `#C31A2B`、警告 `#8F5200`、信息 `#006B8C`（正文对比度达 AA；`#34C759/#FF3B30` 等 vivid 仅用于大字号/图表描边）。
- 深色主题使用纯黑底 `#000000` + `#1C1C1E` 表面 + `#0A84FF` 主色，与 iOS 深色语义一致。
- 旧变量（`--primary/--surface/--canvas/--line/--text/--income/--expense/...`）全部保留并指向新 Token，因此 60+ 既有页面自动获得统一视觉，无需逐页重写。
- 玻璃效果只用于顶栏与移动底栏，并有实色回退色；不做全屏 `backdrop-filter`。

### 2.2 字体

- 系统字体栈：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "SF Pro Display", "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Segoe UI", sans-serif`。
- 金额全部 `font-variant-numeric: tabular-nums` + `font-feature-settings: "tnum" 1`；不使用或引入任何 Apple 字体文件。
- 金额层级：Hero 38–56px / 卡片指标 22–28px / 行内 14px，标签 12px，辅助 11px。

### 2.3 卡片与间距

- 卡片圆角 16–28px（`--pf-radius-lg/xl/2xl`），1px 精致边框 + 低层叠阴影（`--pf-shadow-1/2`）；内边距 20–26px；模块间距 18px（移动 12px）。
- 避免大面积渐变：仅 Hero 有极浅的径向 tint；不使用装饰性玻璃卡片。

### 2.4 动效

- 自然缓动 `cubic-bezier(.32,.72,0,1)`，120/200/320ms；Hover/Focus/展开/收起/页面切换均有反馈。
- `prefers-reduced-motion: reduce` 下关闭过渡、骨架闪动与图表动画；图表默认动画在减弱动效时关闭。
- 不做大范围位移动画；骨架仅做低对比微光。

### 2.5 共享组件（新增）

| 组件 | 作用 |
| --- | --- |
| `AppleCard` | Apple 分组卡片：标题/副标题/动作/网格 span/loading/footer，纯 `section` 避免与旧 `.ant-card` 覆盖冲突 |
| `AppleSegmented` | macOS/iOS 分段控件，WAI-ARIA tablist + 方向键/Home/End |
| `AppleChart` → `EChart` | 懒加载 ECharts 包装，主题化坐标轴/tooltip，`role="img"` |
| `AppleStat` / `DeltaBadge` | 统一指标与涨跌徽标；金额经 `Money`，隐私模式自动遮罩 |
| `SkeletonCard` / `AppleEmpty` | 统一 loading / empty 状态 |

## 3. 首页（`/`）重构说明

定位：**个人财务控制中心**。

1. **欢迎区**：Asia/Shanghai 日期与星期、按时段问候（早上好/下午好/晚上好，h1）、由真实数据生成的状态句（本月结余、可用预算、异常待核对数）、全局快捷操作（记一笔 / 全部交易 / 分析工作台）。
2. **净资产 Hero**：净资产、总资产、总负债；7/30/90/1 年区间切换（`AppleSegmented`），仅请求当前区间；净变化金额 + 精确百分比 + 区间日期 + 口径说明；缺失汇率外币账户（`excludedCurrencies`）明确提示；点击进入账户。数据来自 `/reports/summary`（含期初单日快照），无写死金额。
3. **财务概览**：本月收入 / 支出 / 结余 / 可用预算 / 储蓄率 / 近期现金流，真实接口聚合；月份选择器（`aria-label=选择账期`）+「本月/历史月份」标签；每项可点击到对应详情；历史月份标注「规划汇总为当前口径」，不伪造历史规划数据。
4. **快捷操作中心**：记一笔 / 收入 / 支出 / 转账（复用右侧快捷记账抽屉 `openEntry`）、智能自动对账、AI 消费审批、消费价值分析、人生财务模拟、独立记账中心（`/bookkeeping/new`）——全部是真实存在且可达的功能。
5. **AI 财务洞察**：复用既有 `FinancialInsights`（DeepSeek、分项授权、工具依据、生成时间），外层明确展示「分析期间 / 数据依据 / 生成状态」；未配置时只显示未配置状态与配置入口，不生成伪结论。
6. **待处理财务事项**：`/transactions/summary`（待确认、异常、未分类）+ `/smart-reconciliation/overview`（待复核、冲突、覆盖率）；无账单时如实显示「暂无对账数据」；展示服务端统计口径原文与入口。
7. **最近交易**：Apple 列表行（分类类型图标、交易名、时间、账户、金额），点击进入交易详情抽屉，底部查看全部。
8. 每个模块独立 loading / empty / error；隐私模式隐藏金额且不渲染图表（`pf-chart` 数量 0）。
9. 响应式：≥1181px Hero 8 列 + 待处理 4 列；≤1180 全宽；≤760 欢迎区仅保留「记一笔 + 分析工作台」，快捷操作 2 列且隐藏副标题；≤380 单列。

## 4. 仪表盘（`/dashboard`）重构说明

定位：**专业财务分析工作台**，模块化 Bento Grid（12 列 → 平板 6 列 → 移动单列）。

| 模块 | 数据来源 | 关键能力 |
| --- | --- | --- |
| 收入与支出趋势 | `/reports/summary`（月度） | 6/12 个月切换，收入/支出柱 + 结余线，tooltip 精确金额 |
| 净资产历史变化 | `/reports/summary` + 期初快照 | 30/90/365 天切换，期末/期初/净变化/百分比，账本口径与外币排除 |
| 资产与负债结构 | `/dashboard.accounts`（主）+ `/assets/allocation`（缺口提示） | 按账户类型汇总正余额；信用卡/贷款计入负债；**按币种过滤**，外币账户单列说明；不双计 |
| 消费分类分布 | `/dashboard.categories` | 环形图 + 排行 + 占比，点击下钻 `/transactions?categoryId=&month=` |
| 预算执行情况 | `/dashboard.budget` | 总进度 + 分类进度，超预算/接近预算状态，链接预算管理 |
| 现金流分析 | `/cashflow/forecast` | 30/60/90 天切换，期初/流入/流出/期末/自由可用，日余额面积图，assumptions 与未解决项提示 |
| 储蓄率与结余趋势 | `/reports/summary` 月度 | 结余柱 + 储蓄率线；收入为 0 的月份标记不可计算，不补零造假 |
| 财务目标进度 | `/savings-goals` | 进度条、剩余、目标、目标日期，超期提示 |
| 异常交易与待对账事项 | `/transactions/summary` + `/smart-reconciliation/overview` | 待确认/异常/未分类、待复核/冲突/覆盖率；无账单空状态；统计口径原文 |
| AI 财务分析摘要 | `/ai/chat/stream` | 复用真实 AI 洞察，期间/依据/生成状态可见；未配置不生成 |

其他能力：

- **统一筛选**：账期 DatePicker + 区间分段控件；月份类模块共用 `month`，当前类模块（现金流/目标/异常/AI）明确标注「当前」；页面常驻可折叠「统一统计口径」。
- **布局持久化**：模块显示/隐藏、上移/下移、恢复默认，写入 `localStorage pf-apple-dashboard-v1`；全隐藏被 normalize 拒绝；刷新后保持。
- **保留既有能力**：交易日历、最近交易、账户资产、待确认与到期提醒、预算与财务规划、历史上的今天、统计口径说明、快捷操作全部保留在「更多工具与明细」，移动端默认折叠（高度 -27%），功能不丢失。
- 模块级错误隔离：单个接口 503 只影响该模块，其余正常渲染；隐私模式优先于 loading，9 个模块显示隐私占位且不渲染 canvas。

## 5. 图表设计

- 低噪声：隐藏多余网格线/坐标轴刻度、虚线分隔、紧凑「万/亿（英文 K/B）」轴标签、精确 tooltip、时间范围切换。
- 全部图表经 `AppleChart` 懒加载；构建产物中 ECharts 独立为 `chart-engine`（412KB / gzip 142KB）与 `chart-renderer`（176KB）异步 chunk，不进入入口首屏（入口 `index` chunk 仅保留动态依赖映射）。
- 金额/百分比/日期统一格式化；空数据、缺失数据、隐私模式、减少动效均有明确状态。
- 收入、支出、转账、还款、退款口径严格沿用后端聚合结果；前端不加载全量交易做统计。

## 6. 全局布局

- 桌面：可折叠 macOS 风格浅色侧边栏（240/76px）+ 单一材料工具栏（68px，sticky）+ 响应式内容网格（内容最大宽度 1740px）。
- 平板：卡片自动 6 列/2 列，导航可折叠，分段控件/筛选不溢出。
- 移动：单列卡片、关键指标优先、触控目标（新建控件）≥44px、无横向溢出、底部触控导航。
- 键盘：原生 button/a、跳过导航链接、`:focus-visible` 2px 主色描边、Escape 关闭弹层、分段控件方向键/Home/End。
- 全站既有页面因 Token 继承自动获得 Apple 配色、字体与圆角；未改其业务实现。

## 7. 性能与稳定性

- 无重复请求：被动加载 `/` 23 个 API、`/dashboard` 31 个 API，0 重复 URL（脚本实测）。

- 未改写任何已验证的财务计算逻辑（金额仍由后端聚合，前端只做展示与百分比派生）。
