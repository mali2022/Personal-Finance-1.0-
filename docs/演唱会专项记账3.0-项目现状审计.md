- ConcertModels.cs：场次、订单、费用、计划、退款、同行人；金额和状态转换规则。订单以数量与座位字符串记录，不等同逐张票档案。

- InterestPanel.tsx：日常、档案、收藏、分析交互；没有强制商品关联场次。
- docs/music-interest-delivery-20261029.md：历史验证报告，仅为历史证据，不当作当前测试通过。

先完成服务/报表/财务验证的逐项调查，再补P0缺口；P0通过后开展P1，随后P2/P3。当前没有新增模型、迁移或业务代码，不需要应用数据库迁移。既有StoredDocument可复用，但新文档类型仍须验证引用、用户隔离、版本、幂等与查询性能；不能用无DDL迁移代替兼容测试。若引入关系表，须先验证隔离库Up、历史数据兼容、约束及恢复方案，再考虑正式迁移。
