# 财务统计口径管理（6.5.0）

入口：设置与管理 → 财务统计口径管理。此阶段未独立发布，功能并入6.6.0 / 2026.10.22.1。

## 规则与边界

沿用账本真实支持的三个统计开关：手续费、资产损失、减少余额的调整是否计入支出。默认只纳入手续费；提供默认、不含手续费、含损失与调减三个组合，并允许独立修改。退款按到账日冲减费用，保留负净支出；不提供会改变账本语义的本金计收入或混合币种开关。

页面列出收入消费、退款、转账及还款、借贷报销、余额资产、时间币种、交易状态及专项指标边界。更改规则会重算历史统计，不改变原交易、余额与净资产。专项薪酬归属月和账户资金流动不等于普通收支。

## 预览、保存和审计

`POST /api/settings/statistics/preview?month=YYYY-MM&currency=CNY` 接受现有 RulesInput，仅查询当前认证用户的账本。按上海月份和原币隔离，复用 Range 和 StatisticalExpenses，返回净费用、手续费净额、资产损失、调减、保存前与方案支出及结余。没有保存操作，不创建审计或修改规则。

保存继续使用原 PUT 接口与 If-Match 并发保护。预设、撤销和预览均不保存；失败保留编辑内容。成功失效查询缓存，避免其他财务页面保留旧口径数据。

`GET /api/settings/statistics/history` 返回当前用户 StatisticsRules 的最近50条审计，使用已有审计记录，无需数据库迁移。页面转换审计字符串 True/False 为开启/关闭，显示修改前后值，时间按上海时区。
