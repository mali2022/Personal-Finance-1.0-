# AI 全功能与统一财务读取授权开发验收报告

日期：2026-10-28（Asia/Shanghai）
候选版本：2026.10.28.3 / 6.13.2
状态：代码已修改，尚未部署；最终验收未全部完成。

## 1. 限制移除

- DeepSeekUsageService：删除每日次数、任务模型次数、累计 Token、日/月费用预算检查及费率必填逻辑；Reserve 仅检查授权并记录尝试，Record 保留可选费用统计。
- AiAgentService：取消模型次数、累计 Token 和工具次数预算中断；使用量计数仍保留。
- DeepSeekChatService：取消快问/深度分析工具预算和固定推理轮数；模型可继续查询直到完成、取消、超时或真实服务商错误。
- AiAgentConfigurationService：旧预算字段为 API/JSON 向后兼容保留，不再作为配置校验或执行条件；费用预算归一为 null。
- 解除隐式全账户查询的 1000 账户拒绝逻辑；显式账户选择仍校验归属。
- 去除保存财务报告的固定一百万字符门槛。
- 保留模型上下文、单次输出容量、超时、并发、重复查询、审计存储和上游真实限制。这些是运行时保护，不是费用配额。

## 2. 授权与隔离

- 新增 AiPrivacySetting.FullFinancialAccess，默认 false；不自动扩大已有用户的历史授权。
- 用户明确保存后，统一映射至现有汇总、交易、工资、本人家庭代付及识别文字读取权限。
- 统一设置页面保存时清除旧分项读取许可；撤销后不经由隐藏的旧许可保留财务读取。
- 权限变更沿用 ConsentVersion、任务取消、工作流停用和审计机制；模型预留、工具执行以及缓存命中前均检查授权版本。
- 所有查询仍由服务端 user 身份进入原财务领域服务。显式单次账户选择保持有效；全量授权不再被旧高级设置的账户配置阻挡。
- 新授权不创建任何写操作授权；原有计划预览、版本检查、写入授权及高风险独立确认保留。

## 3. Copilot 调用链

自然语言 -> 授权与身份 -> 查询计划/模型工具调用 -> 受控领域查询 -> 计算及依据 -> 模型分析/结构化报告。

移除应用预算对这条链的截断；保留财务事实依据、口径、数据缺口及写入确认机制。沿用现有分页交易查询、交叉聚合、实体枚举、对账工作台、现金流及风险等工具；新增投资收益计算入口、人生模拟依据入口、历史人生方案与结果分页枚举。
