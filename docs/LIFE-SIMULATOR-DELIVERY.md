## 1. 功能与当前边界

入口 `/planning/life-simulator`，归属“预算与计划”。支持读取并冻结授权个人财务基准、显式假设、1–480个月模拟、六类决策预设、通用事件编辑、情景保存/复制/版本更新/删除、不可变历史运行、2–6方案比较、现金与净资产曲线、债务与收支曲线、目标触达、单/双变量敏感性及固定种子 Monte Carlo。

基准只包含当前认证用户个人账本。共享空间基准尚未实现，不通过选择其他用户、账户或家庭空间绕过权限。非即时现金保守放入受限资产；用户必须审核可投资资产分类。未匹配还款条款的负债保留在 `UnscheduledDebt`，明确提示未模拟其付款，不能解释成“没有还款义务”。

本版不是完整的税务、养老金、抵押贷款或退休建议系统。未实现项见第18节。

## 3. 财务计算规范

模型版本 `life-monthly-2`。金额使用后端 decimal；生成利息与逐期估值时四舍五入到分（AwayFromZero）。收益/增长/通胀输入为小数，0.03表示3%；贷款预设的界面利率使用百分数，转换后写入DTO。

模拟周期为 `[Start.AddMonths(m), Start.AddMonths(m+1))`。逐日遍历有效事件和真实日历日期；不是每月固定30天。家庭月收支在每期首日净额发生，期中月收入/费用变更从下一期生效；此假设在界面及结果中公开，不声称实现工资日与每日消费的完整细分。周期事件用原发生日 AddMonths，结束日包含当天；同日借款优先，其余按事件ID排序；还款在该日事件之后处理。

贷款采用月利率=年利率/12，复用 LoanScheduleMath 的日历到期日。当前没有实际天数计息、浮动利率、逾期处罚或自定义逐期还款。额外偿还本金默认保持原计划月供（等额本金则保持每期本金）、缩短期限；也支持 LowerPayment 保持到期日并重算剩余付款；每期利息依实际剩余模拟本金重算。期末投资及其他可估值资产按月有效收益 `(1+r)^(1/12)-1` 估值；受限资产不增长、不自动提款。负现金明确保留，不自动创建贷款或出售住房。

## 4. 守恒与分类

每个月运行时强制检查两条恒等式，失败即拒绝结果：

```
期末现金 = 期初现金 + 外部收入 - 实际费用 - 投资净投入
         + 借款取得 - 还本 - 利息 - 资产购买 + 出售所得
期末净资产 = 现金 + 投资 + 其他资产 + 受限资产 - 贷款 - 未排期负债
净资产变动 = 外部收入 - 实际费用 - 利息 + 估值/处置损益
```

内部转账：聚合现金/净资产不变。投资投入：现金换金融资产。购买房产：现金换房产；借款同时增加现金和负债。还本同时减少现金与负债。出售按明确账面价值移除资产，所得进入现金，差价作为处置损益，不重记外部工资收入。交易费与维修费用另用 Expense 事件。估值增长不进入现金。

实际购买力以模拟起点为价格基期；固定通胀按有效月通胀逐期累乘，等价于 `(1+年通胀)^(月数/12)`。随机通胀按路径逐期累乘。当前仅净资产提供实际金额切换，现金、债务、收入费用图明确为名义金额。

## 8. 前端使用

1. 读取并冻结基准，查看缺口，审核起始现金、投资、其他及受限资产。
2. 明确税后收入、生活费、增长、通胀、收益和储备底线。
3. 选择预设，在时间线编辑日期、金额、币种、假设汇率、周期、结束日、出售账面值和关联模拟贷款。贷款/目标目前提供高级JSON编辑，服务端强校验；不是完整引导式表单。
4. 勾选审核后显式计算；取消通过 AbortController 和服务端 CancellationToken；失败保留输入并显示错误，可重试。
5. 保存或另存副本；历史运行打开原报告；选择同口径运行比较。分母≤0时百分比留空。
6. 风险面板显式计算，不对每次拖动或输入触发数据库模拟。查看最近10份概率报告。
7. 打印/浏览器保存PDF，或导出CSV与完整JSON。CSV包含模型、指纹、快照时间、计算时间、币种、期限及完整假设。未提供独立服务端PDF。

页面采用既有Ant Design、ECharts、Query和主题组件；中英文、移动单列/桌面网格。编辑参数后清除旧结果和审核状态，另存期间不允许提前确认。图表有既有“查看数据”辅助入口。数字表格可横向滚动，外层无整页横向溢出。

## 15. Monte Carlo模型

版本 `life-lognormal-1/life-monthly-2`；投资、通胀、收入采用相关月度对数正态变化因子，年对数漂移 `log(1+mean)-volatility²/2`，月波动为年波动/√12。共同相关系数[-0.49,0.99]通过三维Cholesky构造；月份之间独立；月因子截断[0.1,8]，投资费用按有效月费率扣减。

使用显式uint LCG+Box–Muller和固定种子，不依赖 System.Random 的跨版本序列约定。每条路径仍经同一个守恒引擎逐月计算。输出各月净资产P10/P50/P90、期末样本、出现负现金的路径比例，以及有目标时的未专门分配目标触达比例。无目标时比例为null。

验证包括固定种子重复、不同种子改变、分位数顺序、零波动/零费匹配确定性结果、资源及相关系数边界。未校准真实市场分布、时间相关性、税制或罕见事件概率。通胀路径折算购买力，不会自动把所有名义支出绑定随机通胀。固定种子结果取决于模型版本和输入；不是现实成功概率。

## 16. AI与报告

`GetLifeSimulation` 调用真实确定性服务，仅读取本人保存情景与原快照，输出已知口径、用户假设、计算结果和局限。沿用AI Center启用、薪酬隐私授权、受限账户工具拒绝、文本清洗和结果大小限制。没有向外部AI发送测试财务数据，也没有进行付费在线模型验收。因此工具接线已实现，但自然语言端到端解释能力不宣称已全部验收。

报告支持浏览器查看、打印/另存PDF、CSV、完整JSON和历史文档归档。敏感性和概率为独立风险面板；统一财务报告中心导航/模板复用、公开分享、完整15章自动结论报告尚未完成。AI不得将模型结果写回工资、账户、贷款或正式交易。
