## 本轮：收益金额与净归因

API amounts 给出原币总收益、净已实现损益、未实现损益变化、净分红、净利息，以及已包含费用。各净归因相加必须等于原币投资者现金流总和；未对平返回 ReconciliationFailed，页面不宣称完整归因。

费用已在买入成本、卖出净所得、净现金收入或单独费用损益内，不再次从总收益扣除。期内未实现变化扣除期初未实现；不是把期末累计未实现当作期间收益。报告币总收益为每笔精确历史汇率折算后现金流的总和，汇率缺失为空；原币归因仍可查看。汇率金额独立归因及其他未知成本未支持，不按差额填补。

固定样例：买入10份1000+费用10，卖出4份480-费用5，分红50-税5，利息10，单独费用3，期末6份每份120。总收益237=净已实现68+未实现变化114+净分红45+净利息10；费用23仅供核对。若区间开始前10份价值1100，则期间总收益147，未实现变化24。

最终本轮：后端23/23通过（数学、边界、归因及隔离HTTP，0跳过，15秒）；前端7/7组件通过；类型检查见最终工具记录。首次失败为三处测试期望/文本匹配问题，修正后通过，未放宽金额精度。未执行本轮生产构建或浏览器E2E，未部署，隔离库已清理。此前交易工作区18/18是上一阶段证据，本轮未重复运行。

验收发现并修复：高精度decimal字符串传入仅支持两位小数的Money导致渲染异常，新增投资专用BigInt显示舍入，正负半分远离零，计算/导出保持原精度；ECharts自动ARIA对空值播报NaN，允许现有Chart接收调用方ARIA描述，单资产图明确缺失留空及估值计算项。脚本原有启动竞态增加就绪检查。测试定位按实际中文关闭按钮修正。

## 后续轮：资产收益对比与批量API
