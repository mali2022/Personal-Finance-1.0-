# Personal Finance 4.0 — Phase 1 核心首批交付

> 说明：本文引用的《Personal Finance 测试版 …》系列过程文档已在 1.0 正式版整理时合并删除，内容现见 docs/版本历史-1.0.md 与 docs/维护手册-1.0.md。

## 已交付

- 认证用户、个人账本与明确账户集合绑定；单/多账户收支、分类、余额和净资产范围保持一致。不支持账户筛选的工具拒绝请求，不扩大范围。
- 供应商接口、DeepSeek能力配置、配置与程序集版本快照；整体任务截止、工具总次数、上下文字节和进程内模型并发上限。
- 数据库用户额度锁及模型尝试预留；可配置日/月估算费用预算。未知Usage保留保守占用，不按零费用处理。
- 用户主动开启的会话历史保存，分页/搜索/重命名/归档/删除、反馈、复制、重试、停止及原始查询依据。历史回答不注入新一轮事实上下文。
- 持久交易草稿、每条验证、批量解析预览、单条编辑确认、草稿删除、批量确认；确认继续走原领域服务、资金审计和幂等事务。草稿与正式交易关联在同一事务完成。
- 三级分类完整路径匹配；明确分类、已确认规则、历史商户分类和AI建议的优先处理；规则冲突留待用户选择；只匹配当前用户有效分类和标签，不静默新建。
- AI主要界面中英字典、明确范围、待核验流式状态、手机布局与减少动态设置。输入和分类文本做卡号/手机号/邮箱/凭据基础脱敏，授权版本改变会阻止后续模型尝试和工具调用。
- 请求→模型尝试→工具→会话/草稿→正式交易的关联审计；授权变更审计、历史期限与每6小时清理。

保存历史默认关闭。在“模型与隐私”开启保存后，问题、回答和依据存入本机数据库。默认消息保留90天，闲置会话90天过期；过期内容不再用于上下文，定时清理物理删除。草稿保存与会话历史开关相互独立，确认之前不产生分录。

## 已知限制与下一批

1. AI总览与完整14模块导航、全局Copilot入口尚未完成；原财务页面和独立AI助手保留。
2. 商户别名/规范化去重管理、用户纠错学习、分类图标/颜色增量和账户模糊候选还待实现。当前商户历史匹配使用精确名称，分类候选在服务器形成，最终可在原表单重选。
3. 限定账户范围目前支持汇总/分类/余额/信用账单/冻结资金。其他工具明确拒绝限定范围；不能把整账本结果包装成单账户结果。
4. 财务查询继续采用上海日历及CNY/USD/HKD，未扩展任意账本时区/币种。自然语言草稿当前解析日期，默认表单中午时间必须人工核对。
5. 模型能力是管理员配置，不是自动探测；推理工具和高级路由未验收。没有在本批调用真实付费DeepSeek；旧模型别名可用性应独立联调。
6. 上下文控制采用保守字节上限，不是供应商精确tokenizer。日/月预算约束本应用的配置费率预估，不是上游扣费保证；全局并发限制是每进程。旧领域查询没有全部传递取消Token，取消可能等待单条SQL超时后退出。
7. 卡号/凭据脱敏是基础规则，不能识别所有个人敏感信息；数值校验不证明模型文字的语义正确。流式片段标为待核验，最终答案与依据需核对。
8. 服务端密钥仍兼容现有环境/User Secrets/DPAPI保护存储；没有更换服务账户或治理现有密钥来源。文件OCR、安全扫描、报告快照、预测、长期记忆及自然语言自动化仍按后续阶段执行。
9. 本次没有完整屏幕阅读器/自动对比度扫描、多实例压力、百万账本压测或完整浏览器真实API端到端覆盖；不能用当前测试数替代这些验收。

下一批先完善商户/分类候选与中心总览，再扩展范围工具、输出契约与浏览器真实API覆盖，之后进入Phase 2。详见原迁移实施计划。
